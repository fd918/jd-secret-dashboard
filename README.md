# 密令效果外部看板

只包含外部页面静态程序，可单独放入公开GitHub仓库并启用GitHub Pages。

通过GitHub Pages读取每日公开数据快照；采集设备离线时保留最后保存的数据。

页面提供京东密令与淘宝推广位标签，以及仅管理员解锁后出现的极速版红包效果标签；淘宝可输入PID加入当前浏览器列表。页面支持今日、昨日、近七日、本月、自定义时间和每日明细。关注列表保存在当前浏览器，换浏览器需重新加入。京东和淘宝采集程序、用户访问码、服务凭据和数据库均不在本包；普通视图按完整密令词查询；管理员可点击Logo输入独立口令，解密只读的京东/淘宝全量已同步目录。口令不包含在公开文件中；刷新后重新锁定，原关注列表不受影响。
